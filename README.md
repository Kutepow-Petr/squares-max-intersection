# Курсовая: квадраты с максимальной площадью пересечения (C++)

Учебная курсовая работа по дисциплине «Программирование» 
(СПбГЭТУ «ЛЭТИ», кафедра САПР, 2024).

## Задание

Дано N точек на плоскости (N ≤ 100). Найти все пары квадратов 
с вершинами в этих точках, имеющих наибольшую площадь пересечения. 
Вершины вывести против часовой стрелки.
**Ограничение по требованию преподавателя:** запрещено 
использовать стандартные контейнеры (`std::vector`, `std::string`, 
`std::array`) и связанные с ними функции. Работа с памятью — 
только через сырые указатели и динамические массивы (`float**`, 
`float***`).

## Как это работает

1. `CalcSize` — читает N из `points.txt`, валидирует (0 < N ≤ 100).
2. `GetPoints` — посимвольно парсит точки, отбрасывает дубликаты, 
   пишет отчёт в `protocol.txt`.
3. `GetSquare` — перебирает четвёрки точек и строит квадраты 
   (проверка через разности координат Δx, Δy).
4. `Transform` / `AddSquare` — поворачивает квадрат так, чтобы 
   стороны были параллельны осям; отбрасывает дубликаты.
5. `CalcArea` — для каждой пары квадратов считает площадь 
   пересечения (3 случая: 1, 2 или 4 вершины внутри).
6. `PrintRes` — выбирает пары с `Smax`, выводит в `result.txt`.

## Стек и сборка
**Язык:** C++ (стандарт C++14, MSVC), без внешних зависимостей.
Проект собирался в Visual Studio с флагом `/utf-8`, который отвечает
за запись русскоязычных символов в файлы.
(*Project → Properties →C/C++ → Command Line → Additional Options*,
добавление `/utf-8` вручную).
### Сборка в Visual Studio
Создать пустой Console App C++, заменить `ConsoleApplication.cpp` на
`squares-max-intersection.cpp`, перекинуть в папку проета файл `points.txt`
